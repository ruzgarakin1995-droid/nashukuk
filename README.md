# Kılıçoğlu Hukuk Bürosu & Danışmanlık (V2 Teması) 🏛️⚖️

25 yılı aşkın tecrübesiyle lider hukuk bürosu kurumsal web sitesi.

## 🚀 Projeyi Çalıştırma

1. Bağımlılıkları yükleyin:
```bash
npm install
```

2. Geliştirme sunucusunu başlatın:
```bash
npm run dev
```

3. Tarayıcınızda açın:
[http://localhost:3000](http://localhost:3000)

## 📁 Proje Yapısı
- `src/app/`: Sayfalar (Anasayfa, Çalışma Alanları Detay, Emsal Vakalar, Hukuki Makaleler)
- `src/themes/law/v2/sections/`: Hero, Hakkımızda, Alanlar, Vakalar, Avukatlar, Makaleler, SSS, İletişim, Footer
- `src/themes/law/v2/components/`: İnteraktif Randevu Stüdyosu Modal (WhatsApp entegreli), Çok Dilli Dil Seçici, Split Giriş Açılış Perdesi
- `public/law/`: Yüksek çözünürlüklü hukuk, avukat ve emsal dava görselleri
